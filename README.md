# 🌟PREM KUMAR MAHANTY — Personal Portfolio

This is my personal portfolio website, built with **React** and **Tailwind CSS**, to showcase my skills, projects, achievements, and experience as a **Full Stack Developer** ,**Competitive Programmer** and **AI/ML Developer**

## ✨ Features

- **About Me**: Introduction and background.
- **Skills & Technologies**: My technical stack and expertise.
- **Projects**: Highlights of my best work with live demos and code links.
- **Experience**: My professional and leadership journey.
- **Education**: Academic background.
- **Achievements**: Notable recognitions and milestones.
- **Coding Profiles**: Links to my competitive programming profiles.
- **Contact**: Easy way to get in touch.

## 🚀 Tech Stack

- React (with Vite)
- Tailwind CSS
- Lucide React Icons
